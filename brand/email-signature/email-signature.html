About the logo: when you copy, the logo is loaded from a public copy on GitHub, so it shows for everyone you email right away. Once the website is live on www.permavialandscapes.com, it can be switched to the website's own copy. If you pasted the signature before, delete it and paste it again.

How to add it in Namecheap Private Email (webmail)

  1. Click Copy signature above.
  2. Open privateemail.com and sign in to info@permavialandscapes.com.
  3. Go to Settings (gear icon) → Mail → Signatures → Add new signature.
  4. Name it Permavia, click in the big box and press Ctrl + V. Choose to use it for new messages and replies, then Save.
  5. Send yourself a test email to check it.

If the logo still doesn't show: in the signature editor, delete the empty logo box, click the insert image button and choose permavia-logo@2x.png from this folder. Set its width to 186.
